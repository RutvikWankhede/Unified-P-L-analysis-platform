# Accessibility Report

## Status: PASSED ✅

1. **Keyboard Navigation:** Global Search fully supports keyboard mapping (`Ctrl+K` to open, `Escape` to close).
2. **Color Contrast:** The dark mode implementation ensures high legibility and contrast ratios exceeding WCAG AA standards.
3. **Semantic HTML:** Main content is wrapped in `<main>`, structural roles are maintained across sidebars and sections.
4. **Visual Cues:** All statuses rely on color + icon + text (e.g., Warning triangle for failed jobs, arrow up for growth).
